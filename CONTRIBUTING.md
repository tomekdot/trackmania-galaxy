# Contributing to Trackmania Galaxy

Thanks for helping improve the wiki! The full guide lives on the site:
https://tomekdot.github.io/trackmania-galaxy/docs/contributing/

Quick ways to contribute:

- **Add a map screenshot or record** — open a pre-filled issue using the `map-record`, `map-history` or `map-feedback` template (no Git knowledge needed).
- **Edit the docs** — Starlight Markdown pages in `src/content/docs/docs/`.
- **Map data** — `src/data/maps.json` (screenshots and records render automatically on each map page).

Run locally (Node.js 22+):

```bash
npm install
npm run dev   # http://localhost:4321/trackmania-galaxy/
```
