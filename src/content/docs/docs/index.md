Trackmania Galaxy is the community resource for maps, records, guides, gallery pages, and project history.

## What is Trackmania Galaxy?

Trackmania Galaxy is a community-driven wiki focused on documenting gameplay, maps, images, and the history of changes in the project. It started with a ManiaPlanet-oriented structure and has been adjusted to focus on Trackmania Galaxy.

**TrackMania² Galaxy** is a free title pack for ManiaPlanet featuring multiple game modes including **Pursuit** (cops vs thieves), **Goal Hunt**, and **Hunters**. Created by **Dommy** (domino54), it evolved from the original TrackMania² Pursuit title.

## How this site works

- **Static & free** — built with Astro + Starlight, hosted on GitHub Pages. No server, no database, nothing to pay for.
- **Community content** — records and screenshots are added through GitHub issues/PRs, so everything is reviewable and archived forever.
- **Discord archive** — screenshots posted on the community Discord are archived into the gallery, so nothing gets lost in the chat scroll.
