## What You Need

Before jumping in, make sure you have the following:

- **ManiaPlanet** — available on the [ManiaPlanet website](https://www.maniaplanet.com)
- **TrackMania² Galaxy** — free title pack, available in the ManiaPlanet store (search for "Galaxy")
- **Openplanet** — optional but recommended, enhances the overlay with plugins and utilities ([openplanet.nl](https://openplanet.nl))

{: .note }
> TrackMania² Galaxy is completely free. No Planets payment required.

---

## Creating an Account

1. Visit [ManiaPlanet website](https://www.maniaplanet.com) and create a free account.
2. Download and install **ManiaPlanet**.
3. Launch the game and log in with your Ubisoft credentials.
4. In the ManiaPlanet store, search for **TrackMania² Galaxy** and install the title pack.
5. Restart the game — Galaxy will appear in your title pack list.

---

## Joining the Galaxy Community

1. Join our community on [Discord](https://discord.me/pursuit) — the main hub for updates, events, and support.
2. Explore maps and community content on [ManiaExchange](https://tm.mania.exchange).
3. Install [Openplanet](https://openplanet.nl) to access community plugins like the **Event Calendar**.
4. Check the [Pursuit Forum](https://forum.maniaplanet.com/viewtopic.php?t=42646) for official announcements and patch notes.
