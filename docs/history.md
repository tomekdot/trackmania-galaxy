## Name Timeline

### TrackMania² Pursuit (2014–2019)

The project began as **TrackMania² Pursuit**, a cops-and-thieves title pack created by **Dommy** (domino54). The first public release introduced the core Pursuit mode with Police vs Thieves gameplay across multiple environments.

### TrackMania² Galaxy (2019–present)

In **Title Update 1.6**, the title pack was officially renamed to **TrackMania² Galaxy**. The Pursuit mode kept its name — this was a rebrand of the title pack itself, reflecting the creator's vision of a unified collection of game modes (inspired by the abandoned ShootMania Galaxy title).

> "Galaxy is different than anything else in TrackMania. It's an ever-expanding collection of various game modes introducing new gameplay mechanics and tactics to learn."
> — Dommy (domino54), Title Update 1.6 release post

### Trackmania Galaxy Wiki (2024–present)

The documentation was later updated to focus on Trackmania Galaxy while keeping the same community-driven structure and GitHub Pages hosting.
